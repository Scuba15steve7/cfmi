# AI reviews — index

Educational research products. CFMI scores living bills against [CHARTER.md](../CHARTER.md) using [METHODOLOGY.md](../METHODOLOGY.md), publishes conflicts, and offers open fix / alignment language for bipartisan comment. These are **not** legal advice, voting instructions, or counsel to any person.

**Human editor:** CFMI bootstrap (unless a review names otherwise). AI assistance is disclosed on each review.
